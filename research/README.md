# Research scaffolding

This directory contains protocols, schemas, sanitized fixture guidance, and explicitly linked bounded results. It does not substitute these records for broader empirical claims.

- `schemas/result.schema.json` defines the shape of a future recorded result.
- `fixtures/README.md` defines what sanitized fixture data may contain.
- `results/` contains only results linked from a protocol.

Protocols MUST record a source, scope, date, and revalidation condition before a result file is added.
